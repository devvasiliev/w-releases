# Правила проекта

Настройки проекта, код задач и список репозиториев принадлежат
`w-tooling/config/project.json`. Команды можно вызывать из checkout tooling.

- Для первого запуска используй `$prepare-env`.
- До изменений прочитай [порядок работы](.codex/rules/workflow.md).
- Настраивай окружение через `prepare.sh`; секреты храни локально.
- Соблюдай локальный раздел этого файла.
- Перед изменением найди текущего владельца поведения и его проверки.
- Сохраняй незакоммиченные изменения других задач.
- Публикация, создание коммита и deploy требуют прямой команды оператора.

`npm run notion -- doctor` показывает доступные поля и статусы подключённой базы.
`npm run agents:check` проверяет сгенерированные инструкции.

## Локальная ответственность

Runner применяет ZIP указанного release set. Проверяй checksum каждого файла,
двойной preflight и обратный rollback каждого начатого deploy.
Постоянные данные принадлежат сервисам. Hooks сохраняют volumes и схему данных.
Проверки: `bash tests/run-release.test.sh`.
