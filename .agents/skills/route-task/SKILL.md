# Маршрутизация задачи

Прочитай `config/project.json` tooling и локальный `AGENTS.md`. Код проекта
настраивается оператором. Для подключённого Notion найди задачу штатной командой
`npm run notion -- find CODE-N` либо по URL и сверь её содержание с запросом.
Код с нулевым номером, например `ACME-000`, обозначает согласованную локальную
техническую работу. Для него поиск и создание задачи в Notion не выполняются.

До записи изучи текущий контракт, код и проверки. Для внутреннего изменения
продолжай реализацию с подходящими тестами. Для багфикса воспроизведи отказ и
добавь регрессионную проверку. Для нового поведения согласуй требования и
проверяемый результат; применяй OpenSpec, если этот процесс принят проектом.

Сообщи код, владельца, маршрут и следующий шаг. Сохраняй область переданной
работы, существующие правила и изменения других задач.
